## 它比原版多了什么

| 改动 | 说明 |
|---|---|
| 验证码支持邮箱 | 民间 bot 发不出私聊时，验证码改寄 `<旧QQ号>@qq.com` |
| 移除「答题」验证 | 答题拦不住抢号，整套出题 / 判题逻辑已删除（净减约 800 行） |
| 移除「答错锁定 12 小时」 | 只服务于答题，一起删掉 |
| 修复邮箱发不出去 | 旧版 SMTP 端口硬编码 25，而云服务器普遍封 25；现默认 **465 + SSL**，且支持在地址里写端口 |

配置项相应变化：

- **删掉**：`identityBindQuestionCount`、`identityBindKeepQuiz`、`identityBindFailCooldownSec`
- **新增**：`identityBindUseEmailCode`（默认关）
