# 海豹 fork 版说明（相对官方 sealdice-core 的改动）

> 适用产物：`dist-build/sealdice-chat-console-windows-amd64.exe`（Windows amd64 便携版，WebUI 已内嵌）
> 版本：`1.6.2-dev`　基线：官方 `sealdice/sealdice-core` master `4c2d1603`（2026-10-03）
> 本仓库相对官方多出 **96 个提交**，可以用 `git log --oneline upstream/master..master` 自己核对。

下面按"你会用到的功能"分组，先写**新增能力**，再写**修复**，最后写**限制与回退**。

---

## 一、官方 QQ 聊天控制台（新增，最大的一块）

以前骰主想看官方机器人收到/发出的消息，只能翻服务器日志；现在 WebUI 里直接有一个类似桌面 QQ 的界面。

**入口**：WebUI → 扩展功能 → **聊天控制台**

| 能力 | 说明 |
|---|---|
| 会话列表 | 官方机器人参与过的群与私聊：群名/昵称、最后一条消息、未读角标、在线状态、`仅 @ 消息` 权限提示 |
| 消息流 | 群成员 / 骰子自动回复 / 骰主控制台发送，三种来源用不同颜色气泡区分；支持"加载更早的消息" |
| 发送文字 | 以机器人身份发言；群聊不受额度限制，私聊受官方主动消息额度限制（失败会显示原因） |
| 伪引用 | 悬停消息「回复」→ 正文前加「回复 某人：原文」。官方主动消息不能挂 `msg_id`，做不了真引用 |
| @ 群成员 | 群聊输入框旁「@成员」，从最近发言过的成员里选，发成官方 `<qqbot-at-user>` 标签 |
| 发图片/语音/视频/文件 | 输入框「图片/文件」，≤30MB；复用适配器富媒体上传（含分片上传保留文件名） |
| 撤回 | 悬停自己/骰子的消息「撤回」；官方只允许撤回机器人自己发的消息 |
| 禁言 / 解禁 | 群成员消息悬停「禁言」：1 分钟 / 10 分钟 / 1 小时 / 1 天 / 解除；需要机器人是群管理员 |
| 头像 | 私聊会话与每条消息显示 `thirdqq.qlogo.cn` 头像（后端按 AppID + openid 拼，走代理加载） |
| 置顶 | 会话悬停 📌 置顶，置顶会话始终排最前，不受新消息时间影响 |
| 实时 | SSE 推送新消息；断线自动重连并降级为 8 秒轮询 |
| 手动改名 | 群名拉不到/被省略号截断时自己起名，之后不会被官方群名覆盖 |
| 存储管理 | 顶部「存储」：总占用、每群占用/条数、保留天数（0=永久，上限 3650 天）、清空单个会话、清空全部 |

**数据位置**：`<运行目录>/data/default/chat-console/`（独立 SQLite 库 `console.db` + `settings.json`），
**不动** `data.db`、不改任何既有 schema；删掉这个目录等于清空控制台历史，官方版程序不认识它。
旧版 `index.json` + 按天 jsonl（v1.1 及以前）会在首次启动时自动导入，原文件挪进 `legacy-jsonl/`。

**平台限制**（不是本版 bug）：群消息全量取决于群主在官方群设置里授权；官方不提供历史回溯，
只能记录启用之后的消息；媒体链接有有效期，过期后只能显示"图片已过期"；私聊主动消息有额度。

## 二、官方 QQ 身份与日志双向共通（identity-bind）

同一玩家在不同 bot / 不同群的身份与跑团日志可以打通，避免"换了 bot 就换个人"。

- 绑定指令：`.bind` 系列 + `.group bind`，支持群内验证码、**私聊验证码（防抢号）**、**邮箱通道**（邮箱按邮件配置自动判定，无需额外开关）；
- 骰主兜底：`.group bindforce` 手动确认，绑定成功通知改为被动回复（避免占用主动额度）；
- 日志归一：绑定后 `.log` 只列归一后的那一份，官方群自己那份隐藏但不删除；单边绑定会在医生报告里给警示；
- 双 bot 同时在线、跨 bot 日志去重（可选）、全局限频记账、权限门槛、panic 防护等；
- 细节见 `docs/identity-bind-and-ghcr.md`。

## 三、官方 QQ 虚拟角色状态栏（`.sn`）

官方机器人**不能改群名片**，所以 `.sn` 设的属性模板在官方 QQ 上原本完全没效果。
本版把模板当成"虚拟状态栏"，渲染在掷骰 / 检定回复的顶部（QQ Markdown 小号红字）：

```
$\scriptsize\textcolor{#E5484D}{\text{调查员甲 HP12/12 AC16}}$
调查员甲的"侦查"检定结果为: (1)=1/50 成功
```

- 属性实时求值，**不硬编码**规则字段，COC / DND / FU / SH / 自定义扩展都能用；
- 角色名跟随"当前绑定的角色卡"，`.pc` 换卡立刻生效；
- `.sn off` / `.sn none` 自动不显示；关掉「使用 Markdown」时不注入公式（否则会露一串源码）；
- **`.sc`（理智检定）的回复不显示状态栏**（本次修复：`.sc0/1d6` 这种无空格写法以前漏判，会照样加状态栏）。

## 四、安全：出站敏感词打码 + 帮助文档图片化

- **出站打码**：命中敏感词时只替换命中部分，不再把整条回复吞掉；警告 / 拉黑 / 计数逻辑照常；
  开关在 WebUI「拦截管理」里（`maskEnable`）。
- **帮助文档图片化**：可把长帮助文档渲染成图片发送（自带渲染后端 `tools/helpdoc-render`，
  也可自部署），WebUI 里有开关与 URL 配置（`imageRenderEnable` / `imageRenderUrl`）。
- 细节见 `docs/helpdoc-image-and-censor-mask.md`。

---

## 五、帮助文档渲染排版优化

纯文本帮助文档的排版重做：自动分段、标题升格（带底纹）、列表 / 分隔线识别、行首禁则、
搜索"词条: xxx"与短标签行识别；三套配色（paper / 等宽等）、字号行高与内边距调大。
渲染后端的代码已拆到独立文件夹与独立 module，不再进主程序构建。

## 六、日志上传（染色器）修复

- 上游 #1811：缓存链接失效时自动重新上传（探测后端 `load_data`，404/410 判失效）；
- **本版修复**：部分染色器后端是 SPA，任意路径都返回 `200/206 + index.html`，旧逻辑会把这种 200
  当成"链接有效"，导致**永远不重传**；现在按"无法确认"处理 → 会尝试重传（失败仍回退旧链接并提示）；
- **新增**：日志页每个日志卡片「强制重传」按钮 / 接口 `{"force": true}`，用于换了染色器前端域名后
  把旧链接刷成新域名（因为"日志还在后端"时，正常上传会直接复用旧链接）。

## 七、官方 QQ 适配器其它修复

- 发**文件**必走分片上传，修回"未命名"（腾讯 base64 方式不支持自定义文件名）；
- 富媒体 URL 方式的上传时限与文件类型分支；
- Webhook 模式补齐 `op=13` 回调地址验证回包；
- **群组管理页补全官方群名**：官方群名只在 `/v2/groups/{id}/info` 里给，现在先取聊天控制台已拿到的名字，
  缺失时后台限流去官方接口查一次并写回，页面不再全是「未获取到」。

## 八、WebUI（`chaye2333/sealdice-ui` fork）

- 聊天控制台页面（含 **手机端布局**：窄屏会话列表与消息区二选一，不再把标题挤成竖排）；
- 首页**网络质量检测按后端 `targets` 动态渲染**（修官方把检测目标换成平台 API 后，UI 仍写死
  "官网 / Lagrange Sign / Google / GitHub"导致四个红叉的问题），并显示各平台耗时；
- 日志页「强制重传」按钮、图片加载失败显示"已过期"占位、聊天控制台存储面板；
- `Dockerfile` 的 `UI_REF` 钉在本 fork 的具体 commit（`90f4d56`），本地 `static/frontend` 已内嵌同一份产物。

## 九、兼容性与回退

- **数据兼容**：仅在本 fork 的 `BaseConfig` **末尾追加**配置字段（有位置错位回归测试），
  数据库 schema 不变；新增的只有 `data/<实例>/chat-console/` 目录。
- **回退**：换回官方 exe 即可，官方版不认 `chat-console/` 目录、也不会动它；
  详细步骤见 `docs/how-to-revert-to-upstream.md`。
- **未包含**：民间 bot（OneBot）侧的聊天界面；聊天控制台图片/文件的本地缓存（链接过期目前只能显示占位）。

## 十、自己构建（可选）

```bash
# Windows amd64（不需要 CGO）
go build -o sealdice-core.exe .

# 想跑 Docker
docker build -t sealdice-fork .
```

WebUI 源码在 `chaye2333/sealdice-ui`（`Dockerfile` 的 `UI_REF` 指定 commit）；
本地改前端后需要 `pnpm build` 并把 `dist/*` 同步到 `static/frontend/`，再 `go build`（产物会内嵌）。
